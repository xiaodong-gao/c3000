# c3000 当前检出代码逻辑

本文只梳理**现有代码在做什么**，不讨论改法。配方全部写在 `src/main.cpp` 的 `main()` 里，不读命令行参数。

更偏实现规格的对照文档见同目录 [`KLA-style Die-to-Die CUDA C++ Implementation Specification.md`](./KLA-style%20Die-to-Die%20CUDA%20C++%20Implementation%20Specification.md)。本文以当前工程实际调用链为准。

---

## 1. 程序在干什么

输入一张晶圆灰度大图和一份 DieMap XML，按布局切出每颗 die，再对每颗做 Die-to-Die（D2D）差分检出。缺陷坐标最终画回**原始晶圆大图**，并写出 CSV。

当前默认模板策略是：**不指定外部模板图，用本片相邻 die 当参考**。边缘 die 上的大块饱和白区容易和邻居对消，因此另有一条**不依赖邻居**的大白区检测，与 D2D 结果合并。

---

## 2. 入口与运行模式

`main()` 先处理两个开关，再进入切割/检出：

| 开关 | 位置 | 作用 |
|---|---|---|
| `run_tests` | `src/main.cpp` | 只跑 `inspect/SelfCheck.cpp` 回归 |
| `run_bench` | 同上 | 只跑对位/直方图等耗时 |
| 两者都 false | 默认 | `cutdie::run(opt)` 正式流程 |

`cutdie::run()`（`src/die_app.cpp`）再分两条路：

```text
eval_patch_dir 非空
    → 不切晶圆，只评已有 patch（需要外部模板 + eval_truth_dir）

否则
    → 配对 PNG/XML
    → 切割 die
    → （可选）D2D 检出并画回原图
```

正式晶圆流程要 `inspect == true`，并且最终能拿到模板：外部路径，或 `template_neighbor == true` 时用切割结果当模板库。

## 5. 切割：XML → die 框 → patch

### 5.1 读 XML

`parse_die_map()` 从 `<PatternedWaferLayout>` 取晶圆直径、边缘偏移、die 节距、原点偏移、划片槽；从 `<Trimming>` 取 trim；收集全部 `<SkippedDie XIdx YIdx>`。

### 5.2 生成框

`generate_dies()` 与 C3000 / `cut_die.py` 同一套几何：

1. `px_per_mm = 1000 / resolution_um`
2. 布局圆心在去掉左侧 LUT 条之后的晶圆区内，再加 trim 偏移
3. die 中心：`(offset_x + die_x * step_x, offset_y + die_y * step_y)`，单位 mm
4. 四角都落在有效晶圆半径内才生成框
5. 输出索引：`box.x_idx = die_x`，`box.y_idx = -die_y`（图像 Y 向下）
6. LUT：图像左侧列均值 > 100 的连续列宽，框的 x 再加这段宽度

`cut_patches()` 用灰度读入整图，按框裁 patch，文件名 `{图像名}_die_x{X}_y{Y}.png`。XML 标记跳过且 `keep_skipped == false` 的 die 不写图，检出时也跳过。

切割输出（默认 `<图像目录>/<图像名>/`）：

- `patches/` 各 die 图
- `die_overlay.png` 布局预览（可缩小到 `overlay_preview_px`）
- `die_map.csv` 每颗框的像素坐标

检出仍用 `CutResult.full` 和 `boxes` 的**原图像素坐标**，不依赖预览缩放。

## 6. 模板怎么选

`TemplateCache` 三种形态：

| 形态 | 条件 | 行为 |
|---|---|---|
| 单模板 | `template_path` 是一张图，或文件夹里只有一张且文件名无 `die_x*_y*` | 所有 die 共用 |
| 按坐标匹配 | 文件夹内多张 `die_x*_y*` | 用同名坐标那张；`template_neighbor` 时改用邻居 |
| 本片邻居 | `template_path` 空 + `template_neighbor` | `templates_from_cut()` 把本片各 die 放进 `by_xy` |

邻居搜索（`TemplateStore::find_refs`）：

1. 在 16 个偏移里找存在的 die：先十字 ±1/±2/±3，再对角
2. 用灰度重叠区 MAE（`appearance_mae`）打分，**MAE 越小越像**
3. 取前 `want` 张；`want = max(1, template_neighbor_min)`

因此边缘白区 die 往往会先配到**同样有白区的边缘邻居**，D2D 差分里白区被对消。这是后面要单独做大白区检测的原因。

尺寸不一致时 `match_pair_size()` 从左上对齐裁到公共宽高，小于 16×16 则跳过该参考。

## 7. 单对 D2D：`runD2DPipeline`

对「一张模板 + 一张待测 die」执行。直方图 / 对位 / 归一化可分别走 CPU 或 CUDA，算法规则一致。

```text
转 8bit，灰度用于直方图和对位，原图用于后续差分
        │
        ▼
直方图找阈值 → 二值图（gray > T → 255）
        │
        ▼
相位相关 或 ECC（在二值图上估位移）
        │
        ▼
用位移 warp 待测原图（线性插值）和二值图（最近邻）
        │
        ▼
裁公共重叠 ROI（宽或高 < 16 则失败）
        │
        ▼
只在重叠区做辐射归一化，再算 Absolute / Signed / L2
        │
        ▼
极性掩膜 → 门控 L2 → 自适应阈值 → 形态学 → 连通域 → 过滤
```

### 7.1 直方图阈值（对位用）

对灰度直方图高斯平滑后找峰：

- 0 个峰：默认阈值（配方里 125）
- 1 个峰：`(peak + 255) / 2`
- 2 个峰：两峰灰度中点
- 更多峰：最高的两个峰的灰度中点

二值化：`gray > T`。模板和待测各自算 T，`fuse` 只是平均值，检出主路径里对位用的是各自的二值图，不是 fused T。

### 7.2 对位

- **Phase**：二值图相位相关，得到亚像素位移
- **ECC**：二值图 ECC，度量是相关系数 `cc`

`shiftImage` 把待测图按 `(-dx, -dy)` 仿射平移。`commonOverlapRoi` 去掉因平移露出的无效边。归一化**必须**在重叠 ROI 上做，避免黑边污染均值/方差。

### 7.3 辐射归一化

模板**不改**。待测每通道：

`gain = σ_template / σ_data`（σ≈0 则 gain=1）  
`bias = μ_template - gain * μ_data`  
`data' = gain * data + bias`

μ、σ 来自 8bit 直方图的 median + MAD 内点（±3σ），大缺陷不容易把增益拉偏。

然后：

- `absoluteDifference = |template - data'|`
- `l2Difference`：单通道就是绝对差转 float；三通道是欧氏距离
- `signedDifference = data' - template`（灰度 float）

约定：**正 = 待测更亮，负 = 待测更暗**。

### 7.4 极性与融合

1. 亮阈值 `T`：配方 `signedDiff.T > 0` 则用它，否则对 `|signed|` 做 median+MAD
2. 暗阈值 `darkT`：`signedDiff.darkT > 0` 则用它，否则等于 `T`
3. 亮掩膜：`signed > +T`；暗掩膜：`signed < -darkT`
4. 可选黑帽（`darkSpot.enableBlackHat`）：在待测上抓小黑点，并与 `signed < -gate` 相与后并入暗掩膜。当前配方默认关闭
5. `fusedDifference = L2`，极性掩膜为 0 的位置清零——后续阈值只看「够亮或够暗」的差分

### 7.5 自适应阈值

对融合后的 L2：

- 局部：高斯窗口均值 + `k * 局部标准差`，再与 `minAbs` 取大
- 全局：median + `k * 1.4826 * MAD`，同样不低于 `minAbs`
- 像素通过当：超过局部阈值 **或** 超过全局阈值

### 7.6 形态学

顺序：开 → 闭 → 膨胀 → 腐蚀 → 再开（去噪）。核宽 `< 3` 的步骤跳过。最后按外轮廓填充。

若 `darkOpenSize >= 3`，暗掩膜单独开运算后再或进主掩膜，避免大开运算把小黑点吃掉。当前配方 `darkOpenSize = 0`，这条不生效。

### 7.7 候选与过滤

8 连通域。每个 blob 统计面积、bbox、质心、L2/signed 均值与峰值，以及落在亮/暗掩膜上的像素数。

极性：

- 亮像素 ≥ 暗像素 × 2 → Bright
- 暗像素 ≥ 亮像素 × 2 → Dark
- 都没有 → Unknown
- 其余 → Mixed

`filterDefects` 依次卡：

1. 面积：暗缺陷用 `minArea`；亮缺陷再用 `max(minArea, minBrightArea)`
2. `maxArea`（0 表示不限制）
3. 最小宽高
4. 长宽比 `max(w,h)/min(w,h) ≤ maxAspectRatio`
5. 贴边：距图像边 ≤ `borderMargin` **且** 长宽比 > `borderStripAspect` 才丢（细长切割条丢掉，贴边的紧凑黑点留下）
6. 极性开关（当前保留 Bright/Dark，丢掉 Mixed/Unknown）
7. `meanL2`、`|meanSigned|` 下限

通过的候选就是这一对模板/待测的 D2D 结果。坐标在**重叠 ROI** 内，不是整颗 die crop。

## 8. 晶圆级：邻居确认 + 大白区

`inspect_wafer()` 对每颗 die 可能跑多对 D2D。保留「候选数最多」的那一次作为 `pipe`，同时数 `neighbor_hits`（该参考下候选非空的次数）。

### 8.1 双邻居确认

当同时满足：

- `template_neighbor == true`
- `template_neighbor_min >= 2`
- 实际参考张数 ≥ 2
- `neighbor_hits < template_neighbor_min`

则认为小缺陷不可靠（版图差、单邻居上的反相亮斑等）。此时**不是清空全部**，而是只留下：

`极性 == Bright` 且 `面积 ≥ max(400, minBrightArea)`

小暗点、小亮斑在这一步会被丢掉。

评测路径 `eval_patches()` 在同样条件下是 **`candidates.clear()`**，没有「保留大亮块」这条例外。

### 8.2 变到 die crop 坐标

D2D 框加上 `pipe.commonRoi` 的原点，得到相对 **die 裁剪图** 的坐标。

### 8.3 大白区（不看邻居）

`extractLargeWhiteRegions(data, largeWhite)`，`data` 是当前 die 的 crop：

1. `largeWhite.enable` 为 false 则直接空
2. 转灰度 8bit，`像素 ≥ threshold`（默认 230）
3. 椭圆核 5×5：先开（打断细亮桥）再闭
4. 连通域，同时满足：
   - 面积 ≥ `minArea`（默认 4000）
   - bbox 填充率 ≥ `minFill`（默认 0.15）
   - 长宽比 ≤ `maxAspectRatio`（默认 3，丢掉细亮条）
5. 极性固定 Bright；`meanL2` / `meanSigned` 填该区域平均灰度

与已有 **Bright** 候选去重：若与某亮框的相交面积 ≥ 白区 bbox 面积的 30%，视为同一块，不再追加。暗缺陷再小、只要落在白区 bbox 里，也**不会**挡住白区——避免「白区里有一条暗缺陷就把整块白区丢掉」。

### 8.4 画回原图

晶圆坐标：

```text
wafer = crop 原点 + die crop 内坐标
```

大白区本来就在 crop 系，只加 crop 原点。D2D 已先加过 `commonRoi`，再加 crop 原点。

着色：Bright 红，Dark 蓝，Mixed 青，Unknown 灰。有缺陷的 die 画橙色框，无缺陷画绿框。过小的框会放大到可读尺寸。

有缺陷的 die 另存 `die_defects/{图像名}_die_x*_y*.png`（画在 crop 原图上）。

`defects.csv` 列：

`die_x,die_y,id,polarity,x,y,w,h,area,cx,cy,meanL2,maxL2,meanSigned,brightArea,darkArea`

其中 `x,y,w,h,cx,cy` 是**原始晶圆图**坐标。大白区的 `meanL2` 是灰度均值（接近 255），不是 D2D 的差分强度。

## 9. 坐标系

三套坐标不要混：

| 坐标系 | 原点 | 谁在用 |
|---|---|---|
| 晶圆原图 | 大图左上 | `DieBox`、`WaferDefect`、`defect_overlay.png`、CSV |
| die crop | 该 die 在大图中的左上 | `extractLargeWhiteRegions`、单颗 `die_defects` 图 |
| 重叠 ROI | crop 内对位后的有效区左上 | `runD2DPipeline` 的候选、`blobMask` |

映射：

```text
D2D 候选：  ROI → 加 commonRoi → crop → 加 crop.x/y → 晶圆
大白区：    crop → 加 crop.x/y → 晶圆
```

`inspect_wafer` 末尾会把 `pipe.blobMask` 轮廓画到原图上，轮廓点只加了 crop 原点，没有再加 `commonRoi`。位移较大时，这层红轮廓与 CSV 里的框可能差一个 ROI 偏移；框和 CSV 仍以第 8 节的映射为准。

## 11. 评测模式（当前默认关闭）

`eval_patch_dir` 与 `eval_truth_dir` 都非空时：

- 正样本 = 真值目录里的**文件名**集合
- 待测目录逐张跑与晶圆检出相同的 D2D（含邻居）
- 邻居确认失败时清空候选（无大白区、无「保留大亮块」）
- 按「该图是否检出至少一个候选」计 TP/FP/FN/TN
- 写出 `eval_report.csv`、`eval_candidates.csv` 以及 `tp/` `fp/` `fn/` 叠加图

这是 patch 级有/无缺陷评测，不是晶圆坐标评测。

## 12. 实现上需要记住的几点

1. **配方只在 `main.cpp`。** 改检出行为应改那里的 `Options`，不要加命令行。
2. **单模板会把版图差当成缺陷**；当前正式路径用相邻 die，并要求双邻居命中。
3. **D2D 看不到「两边都有的大白区」**；大白区是对本颗 crop 的绝对亮度，不是差分。
4. **亮缺陷面积门限更严**（`minBrightArea`），用来压邻居缺陷反相出来的小亮斑。
5. **贴边不是一律删除**：只有又贴边又细长的才丢，所以 die 顶上的小黑点可以留下。
6. **`clearMaskBorder` 仍在 DefectDetect 里**，当前 `runD2DPipeline` / `detectDefects` 主路径不再在极性阶段清边。
7. **Pipeline 用 `extractDefectCandidates` + `filterDefects`**，不走 `blobFilter()`；`blobFilter` 是同文件里的独立接口。
8. 回归测试在 `inspect/SelfCheck.cpp`（含大白区合成图、贴边黑点、真实 0050 小黑点等），由 `main` 的 `run_tests` 触发。

## 13. 调用关系（晶圆检出）

```text
main
 └─ cutdie::run
     ├─ collect_jobs
     ├─ cut_patches

     ├─ templates_from_cut 或 load_templates

          ├─ TemplateStore::find_refs
          ├─ runD2DPipeline          × 每个邻居
          │    ├─ histogram → binary
          │    ├─ phase / ECC
          │    ├─ intensityNormalize
          │    ├─ applyDefectPolarity

          │    └─ filterDefects
```
